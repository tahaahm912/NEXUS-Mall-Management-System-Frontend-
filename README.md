## 📋 Overview
The **Mall Management System** is a comprehensive web-based front-end interface designed to facilitate the seamless administration of shopping mall operations. This project provides administrators with intuitive dashboards and management tools to oversee events, track system logs, and manage mall entities efficiently.

## 🚀 Features
- **Admin Dashboard (`admindash1`)**: A central hub providing an overview of mall operations and quick access to management tools.
- **Event Management (`adminevent`)**: Dedicated interface for planning, scheduling, and managing promotional events and activities within the mall.
- **Core Management (`adminmanagement`)**: Comprehensive forms and data tables to manage tenants, staff, and physical resources.
- **Activity Logging (`adminlog`)**: A system log interface to monitor administrative actions and maintain security audits.
- **Notifications System (`adminnoti`)**: Alerts and notification components to keep the administrative staff updated.
- **About Us (`aboutus`)**: Informational section outlining the mall's details or system details.

## 🛠️ Technologies Used
This project is built primarily using core web technologies, ensuring lightweight deployment and broad browser compatibility:
- **HTML5**: Semantic markup for page structure.
- **CSS3**: Custom styling for each module to ensure a responsive and cohesive user experience.
- **JavaScript (Vanilla)**: DOM manipulation, interactive UI elements, and client-side validations.

## ⚙️ Installation and Setup
Since this project consists of static front-end files, no complex server setup is required. 

1. **Clone the repository** (or extract the project archive):
   ```bash
   git clone https://github.com/tahaahm912/NEXUS-Management-System-Frontend-](https://github.com/tahaahm912/NEXUS-Mall-Management-System-Frontend-
   ```
2. **Navigate to the project directory**:
   ```bash
   cd "Mall Management System"
   ```
3. **Run the application**:
   Simply double-click on `admindash1.html` or open it in any modern web browser (Google Chrome, Mozilla Firefox, Safari, Edge) to launch the Admin Dashboard.
   
*Note: For the best experience and to avoid CORS issues if fetching local data via JS, it is recommended to serve the files using a local development server (e.g., VS Code Live Server, Python `http.server`, or Node `http-server`).*
